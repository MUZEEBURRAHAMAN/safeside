# Core User Flows

Text versions of the five primary flows. Full detail + branches: `reference/research/UX_Research_Document.docx` §7. Drop flow diagrams/screen sequences in this folder.

## 1. First run & onboarding
Launch → value intro (3 cards) → sign in (Apple/email) → 8-Q profile (skippable) → home / first scan prompt.
- Skip profile → app still works; planner prompts to complete later.
- Defer the paywall; let value land first.

## 2. Scan → understand (core loop)
Tap Scan → camera + barcode → result (score + verdict) → expand "why" (sources) → auto-saved to Pantry.
- Not found → "Snap the label" → OCR → result.
- Poor score → "See a better option" (→ flow 3).
- No camera permission → calm explainer + Settings deep link.

## 3. Verdict → better swap → plan
Poor score → ranked better alternatives → pick one → add to a meal slot → confirmation.
- Ranking: in-pantry → better score → same role/macros → restriction-safe.
- Not in pantry → "Find it next shop" adds to shopping list.

## 4. Build a weekly plan (manual + AI)
Planner → weekly grid → drag from Pantry / search → (optional) AI fill/improve → review & edit.
- AI is an assist layer returning editable suggestions; user edits win.
- Empty state: "Your plan is empty — add a favorite or let AI start it."

## 5. Plan → shopping list → shelf
Plan → generate list → aisle groups (have/need) → at store: Scan to compare → check off.
- Shelf scanning feeds new products back into the Pantry, closing the loop.
