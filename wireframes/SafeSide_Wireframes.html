SafeSide — every screen, module & edge case

High-fidelity wireframes for the native iOS app, rendered with the real Design System v3 tokens — mint-white canvas, bold-green accent, Space Grotesk display type, floating white cards. Each screen follows the five design laws: every verdict is evidence, calm alarm (no red except allergen safety), never a dead-end, honest states, and ED-safe always. Copy is drawn verbatim from the project COPY_DECK.

Badges mark each frame's state: content empty loading error edge case. Frames render at ~360pt logical width (Standard class); the final section shows Compact + XXL Dynamic Type reflow.
